# เซียน · Pool helper: บันทึกส่งต่อ (ถึง v3.16.0)

ใช้ไฟล์นี้เริ่มแชทใหม่เพื่อทำต่อเฉพาะ **WePlay 8-ball Pool** ส่วนเกมอื่นในแอพเสร็จแล้วและอยู่ในโค้ดของ repo นี้

## วิธีทำงานกับ Atom (ผู้ใช้)
- **คุยกันก่อนทำทุกครั้ง** อธิบายสิ่งที่เจอและแผนให้ตกลงก่อนลงมือ ยกเว้นตอนที่เขาบอกให้ "ทำไปก่อน"
- ตอบเป็นภาษาไทยแบบสั้นๆ เข้าใจง่าย ไม่ต้องลงศัพท์เทคนิค
- เขาเล่นเกมบน iPhone แล้วส่ง log กลับมา (`sian-pool-log.txt` เปิดในแอพที่ "บันทึกเกมพูล" แล้วกดแชร์) ส่งภาพหน้าจอได้ แต่ **อัดคลิปตอนเปิดเซียนไม่ได้** เพราะ ReplayKit ใช้ได้ทีละตัว
- ไม่อยากได้เสียงพูด ให้มีแค่เสียงยาวเสียงเดียว 660 Hz เมื่อเล็งแล้วลงชัวร์ กับเสียงติ๊งเมื่อดึงแรงถึงค่าที่แนะนำ
- PiP ต้องเป็นแนวนอน 640×360 วางทับรูปคู่แข่งมุมขวาบน มีโต๊ะเล็กตั้งตรงเหมือนในเกมอยู่ซ้าย ข้อความอยู่ขวา

## ปล่อยเวอร์ชันอย่างไร
- push ขึ้น `main` แล้ว GitHub Actions (`build.yml`) จะสร้าง IPA และออก release `build-N` ให้เอง ลิงก์โหลดคือ `https://github.com/Atomawayg/sian-reversi-ios-/releases/download/build-N/SianReversi.ipa`
- push ขึ้นกิ่ง `dev/**` จะแค่ compile เช็ก ไม่ออก release ใช้ลองว่า build ผ่านก่อน merge
- ขึ้นเลขเวอร์ชันที่ `project.yml` → `MARKETING_VERSION` (ตอนนี้ 3.16.0)
- เช็กสถานะ build ด้วย `gh api repos/Atomawayg/sian-reversi-ios-/actions/runs/<id>` เพราะ GraphQL ใช้ไม่ได้

## ค่าที่วัดแล้ว (จอ 1180×2556)
- พื้นที่เล่น (จมูกยาง): x 207.5–966.5, y 584–2135 ลูกรัศมี R = 23.5 กึ่งกลาง (587, 1359.5) ตำแหน่งทุกอย่างเหมือนกันทุกธีมโต๊ะ (ฟ้า ชมพู ฯลฯ) ต่างกันแค่สี
- จุดศูนย์กลางรูหลุมในฟิสิกส์ (`holes`): มุม (195,570) r40, กลาง (170,1360) r37 แล้วสะท้อนไปอีกฝั่ง
- จมูกหลุมมุม: ขอบบน/ล่างตรงถึง x=261 (อีกฝั่ง 913) ขอบข้างตรงถึง y=641 แล้วจมูกเอียง 45° ยาว 30 px **ค่านี้ขยับเข้ามา 9 px จากที่วัดได้ในภาพ** เพราะใน log ลูก 11 เด้งออกทั้งที่แอพบอกลง
- หลุมกลาง: ช่องเปิด y 1319.5–1399.5 มีจมูกสั้นๆ
- ช็อต "ลงชัวร์" (เขียว + เสียง) ต้องลงแม้จมูกจะหนาขึ้นอีก `safePad = 4` px
- ลูกกระทบขอบ: tan(มุมออก) = 1.28·tan(มุมเข้า) เหลือความเร็วราวครึ่งหนึ่ง (วัดจากชิ่งแค่ 2 ครั้ง)
- ความเร็ว: v0 ≈ 4150 px/s × แรง, dv/dt = −(100 + 1.4v)
- หลอดแรง: x=1080, y 878→1689
- ตาของคุณ: วงเวลารอบรูปโปรไฟล์ศูนย์กลาง (98,365) รัศมี 64–66 นับทุกสีที่ s>0.45 ยกเว้นฟ้า (ตาคู่แข่งเป็นขอบขาว) และกันหลุดไว้ 0.6 วินาที
- แถบลูก: ของคุณ x 206+46.8k y398 ของคู่แข่ง x 697+47k y397 ลูกลายมีหัวขาว (ratio < 0.63)
- วงเล็งของเกม: วงขาวกลวงขนาดลูก ต้องไม่ทับลูกใดๆ และต้องมีเส้นขาวจากลูกขาวลากไปถึง (lineSupport ≥ 0.6) ตอนดึงแรงให้ใช้จุดเล็งล่าสุดแทน
- เส้นทิศของเกม (objDir): แม่นมาก ต่างจากทิศที่ลูกวิ่งจริง < 1°

## สคริปต์ใน `Tools/pool/` (Python + numpy)
- `sim.py`: ฟิสิกส์เวอร์ชัน Python (เรขาคณิตใน `sim.py` เป็นค่าเก่า ให้เรียก `fit.build(9, 40)` จะได้ค่าเดียวกับในแอพ) ส่วน `padsim.py` ใส่ pad ให้จมูก
- `fit.py`: ข้อมูลช็อตจริง A–H กับการ grid ค่า `e` / `rc`
- `shots3.py`, `shots5.py <log>`: ดึงแต่ละช็อตจาก log ว่าแอพบอกอะไร แล้วผลจริงเป็นอย่างไร
- `poolnp.py`: ตัวอ่านโต๊ะเวอร์ชัน numpy (ใช้กับภาพหน้าจอหรือเฟรมจากคลิป), `feltlearn.py` เรียนรู้สีพื้นโต๊ะ, `aimtest.py` ทดสอบการหาวงเล็ง
- log กับคลิปของผู้ใช้ไม่ได้อยู่ใน repo ให้ขอให้เขาแนบมาใหม่ในแชทใหม่ถ้าต้องใช้
